# Brag Document

> Evidence file. Written as things happen, read at review time. Every entry carries a pointer a reviewer could follow — a ticket, a PR, a named person who said it.

## Format

```
## YYYY-MM-DD — <one-line accomplishment>
- What: <2-3 sentences, plain prose, own words>
- Evidence: <ticket IDs / PR refs / "attested by <name> in <context>">
- Why it mattered: <impact in one sentence — time saved, risk removed, person unblocked>
```
